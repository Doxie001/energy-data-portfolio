# Energy Data Portfolio

This is where I keep all my energy data projects. Each one takes a real energy question, works through the data, and turns it into a simple tool or dashboard that non-technical people can understand and use.

The portfolio grows over time. New projects are added as I finish them, so this page is a record of my work, not a single project.

## What this portfolio is about
Energy data is often locked inside long reports and technical tables. My goal is to make it accessible by asking practical questions, such as how electricity supply problems affect businesses and where cleaner energy options make sense, and answering them with clear analysis and dashboards.

## How each project is built
Every project follows the same process, so the work is easy to follow and check:
1. **Define the problem:** state the question and what "done" looks like
2. **Identify who is affected:** know who the analysis is for
3. **Get the data:** use credible, named sources
4. **Clean and analyse:** prepare the data and look for patterns
5. **Build the output:** a dashboard or tool
6. **Document the limits:** say clearly what the work can and cannot show
